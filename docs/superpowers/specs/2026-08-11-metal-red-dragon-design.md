# Metal-Generated Red Dragon Design

## Goal

Create one stylized, interactive 3D red dragon whose geometry is pre-generated by an offline Apple Metal pipeline and exported as a web-ready asset. Display that asset in the existing React Three Fiber application.

## Scope

The first version contains a single dragon assembled from lightweight procedural mesh parts: torso, neck, head, snout, horns, wings, four legs, and a tapered tail. It is intended to read clearly as a dragon rather than reproduce realistic anatomy.

The dragon uses a deep-red metallic PBR appearance with darker horns and wing membranes. The web presentation provides lighting, shadows, orbit controls, and a slow automatic turn so the full model can be inspected.

Animation, skeletal rigging, fire effects, Meshy generation, and multiple dragon variants are outside this first version.

## Asset Generation Architecture

An offline macOS command-line generator owns the asset-building path:

1. Swift defines the dragon's component parameters and launches a Metal compute kernel.
2. The Metal kernel generates vertex positions and normals for reusable procedural primitives and applies each dragon-part transform.
3. Swift reads the completed GPU buffers, combines vertices with triangle indices and material assignments, and exports a binary glTF (`.glb`) asset.
4. The generated GLB is stored under the web application's public assets and is checked into the project so normal web development does not require Metal or macOS.

The generator must fail with a clear message when Metal is unavailable or asset export cannot complete. It must produce deterministic geometry from checked-in parameters.

## Web Rendering Architecture

The existing React Three Fiber renderer loads the generated GLB from a local public URL. A focused dragon showcase component owns model loading, presentation lighting, camera framing, orbit controls, slow rotation, and a loading/error fallback.

The GLB carries material grouping, while the web component applies the final PBR values needed for a red metal finish. The model remains interactive through camera orbit and zoom rather than direct mesh deformation.

## Data Flow

```text
Metal kernel -> GPU vertex buffers -> Swift exporter -> public/red-metal-dragon.glb
                                                        |
                                                        v
React Three Fiber loader -> PBR materials -> interactive WebGL scene
```

## Validation

The generator is validated by confirming that it exits successfully, writes a non-empty GLB, and produces finite vertex positions and normals. The web integration is validated with the existing type/build checks and a browser render confirming that the dragon loads, is framed in view, responds to orbit controls, and shows the intended metallic red shading without console errors.

## Success Criteria

- Geometry is generated through a checked-in Metal compute shader rather than authored only in browser code.
- The exported asset is a local GLB that loads without a Metal dependency at web runtime.
- The silhouette clearly includes a head, horns, wings, four legs, and a tail.
- The web result is interactive, visibly red and metallic, correctly lit, and usable after a normal project checkout.
